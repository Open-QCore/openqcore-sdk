# Changelog

## 0.1.0 (2026-11-26)

First release of the Python (`openqcore` on PyPI) and TypeScript (`openqcore` on npm) SDKs.

- Chat with streaming (text, status, media), sessions and messages
- Voice: streamed voice turns, full-reply audio, text to speech, interrupt
- Iris: image and video generation jobs with `wait`, image download, document OCR
- Knowledge: upload, text items, ask with citations, `wait_until_processed` / `waitUntilProcessed`
- Archive, personal and workspace API keys, models, usage, search, RAG, embeddings, ingest
- Typed errors for every status, retries with backoff and `Retry-After`, timeouts, idempotent chat requests
